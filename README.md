# EchoChain

Skeleton implementation of the EchoChain app.

## Development

1. Install dependencies (requires internet):
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
3. Cloudflare worker dev:
   ```bash
   npm run serve
   ```

## API

See `openapi.yaml` for endpoint specification.
